# GitHub Pages / installable app deployment — 11AM Hikam

## URLs and static hosting

- Canonical site: `https://mohdujjain.github.io/11am-hikam/`
- GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/(root)`.
- Main app: `index.html`; source: `src/main.html` + `src/chapters/subtopic-*.html` + shared CSS/JS.
- Custom accessible error page: `404.html`, which links back to `/11am-hikam/`.
- Sitemap: `sitemap.xml` containing one canonical URL (the whole book is one page).
- Project Pages cannot publish the origin-root `/robots.txt` from this repository. Submit `https://mohdujjain.github.io/11am-hikam/sitemap.xml` directly in Search Console when relevant.

## Social previews

`src/main.html` owns all meta tags; `src/build.py` propagates them to `index.html`. The 1200 × 630 `og-image.jpg` is linked by absolute URL in `og:image`, `og:image:secure_url`, and `twitter:image`. The `summary_large_image` Twitter card uses the same image. Sharing previews are generated by external social services; their crawlers need an online public image and may retain cached thumbnails.

## Offline book and font caches

- The manifest and service worker are scoped to `/11am-hikam/`, never `/`.
- `src/build.py` embeds CSS, JS and every chapter into `index.html` and hashes that build plus supporting assets and the service-worker template. On a new edition the generated worker uses a new cache version.
- Precache must succeed for `index.html`, manifest, icons, social card, 404, sitemap before the new worker replaces the previous version. The old cached book remains usable if a new install fails.
- Navigation uses cache-first, so returning users have immediate offline access.
- Once a newly cached edition takes control, the current page shows a screen-only **New edition ready — Reload book** notice. This only works after users have reloaded into a version containing the notifier (the first upgrade from older installations may need a manual reload).
- The existing CDN Google Fonts stylesheet is retained. While online, the controlled page re-requests observed Google Fonts CSS/WOFF2 resources into `11am-hikam-cdn-fonts-v1`, a separate cache that persists across book editions. This *improves* offline typography but does **not** promise all font variants are available on a first visit or after device eviction; no font binaries are shipped in the repository.
- Optional **Keep on this device** requests browser-controlled persistent storage; it cannot prevent manual deletion or OS-level eviction.

It **reports** errors; with branch-based Pages it does not prevent publishing a broken commit. Use branch protection or an Actions-based Pages workflow if publication gating is required.

## Device validation (after publishing)

1. Check `/index.html`, `/manifest.webmanifest`, `/service-worker.js`, `/og-image.jpg`, `/404.html`, `/sitemap.xml` and both icons return HTTP 200.
2. Open the site in Chrome/Edge → DevTools → Application → Service Workers; confirm scope `/11am-hikam/` and an active worker.
3. Wait for “Entire book saved offline”, then switch DevTools Network → Offline and reload. The 34 chapters and offline UI should display.
4. Reconnect online; inspect Cache Storage for `11am-hikam-cdn-fonts-v1` after page load, then test offline again. Do not assume every variant is cached if this cache is missing or incomplete.
5. Test another build in an already-open installed window. On online update activation, confirm the update banner appears; choose Reload book to see changed content.
6. Test a social link share in messaging apps; some services cache previews independently of your site.
7. Test `/11am-hikam/not-a-page` to see the custom 404 page.

Original 34 dossier content and publishing/print functionality remain unchanged.
